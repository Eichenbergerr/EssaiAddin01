insertImage — Tutoriel

Complément Word Durée ~10 min
Objectif Prérequis Démarrage Étapes Vérifier FAQ

But de l’exercice (sans divulgâcher)

Sur un document Word fourni, vous devez insérer une image à l’emplacement prévu puis ajouter une légende correcte afin que le bouton Tester l’exercice (sur la page du complément) valide votre travail et que l’icône passe de ❌ à ✔️.

Important : utilisez la commande officielle de légende de Word afin que la légende soit liée à l’image (et non un simple texte tapé au clavier).

Prérequis

  • Word 365 (Web ou Bureau). Si une commande n’est pas disponible dans Word Web, ouvrez le document dans Word Bureau.
  • Accès à la page du complément : ouvrir insertImage.html.
  • Manifest pour sideload (Word Web) : manifest.xml — remplacez votrepseudo si besoin.

Démarrage rapide

1) Ouvrir le document d’exercice

  1. Visitez la page du complément : insertImage.html.
  2. Cliquez sur Charger la situation de départ pour générer le document avec l’emplacement prévu.

2) (Si besoin) Sideload dans Word Web

  1. Dans Word Web : Insertion → Compléments → Téléverser mon complément.
  2. Sélectionnez manifest.xml depuis GitHub (téléchargez-le d’abord si nécessaire).

Réalisation — étapes guidées

A. Insérer une image à l’emplacement prévu

  1. Repérez le texte === EMPLACEMENT IMAGE === dans le document.
  2. Placez le curseur juste sous cette ligne.
  3. Insérez une image : Insertion → Images (depuis votre appareil ou banque d’images).

B. Ajouter une légende liée à l’image

Procédez avec la commande de légende intégrée pour que Word associe la légende à l’objet image.

Word Bureau (Windows/Mac)
  1. Cliquez sur l’image pour la sélectionner.
  2. Allez dans Références → Insérer une légende.
  3. Vérifiez que le Libellé est de type Figure. Ajoutez le texte descriptif (court et précis).
  4. Validez. La légende apparaît liée à l’image (style “Légende”).
Word Web (si l’option est disponible)
  1. Sélectionnez l’image.
  2. Utilisez la commande de légende (ou ouvrez le document dans Word Bureau si la commande n’est pas présente).
Astuces qualité :
  • La légende doit être associée à l’image (commande de légende), pas un simple paragraphe saisi.
  • Gardez un intitulé concis et pertinent.
  • Si la numérotation est visible, laissez Word la gérer automatiquement.

Vérifier votre travail

  1. Revenez sur la page du complément : insertImage.html.
  2. Cliquez sur Tester l’exercice.
  3. Si tout est correct, l’icône passe de ❌ à ✔️.

Selon le navigateur, l’état de réussite peut être gardé dans le localStorage pour cette machine.

FAQ — Problèmes courants

Le bouton de test reste sur ❌

  • L’image est-elle bien insérée sous la ligne d’emplacement ?
  • La légende a-t-elle été ajoutée via la commande de légende (et non tapée à la main) ?
  • La légende est-elle directement associée à l’image sélectionnée ?

Je ne trouve pas “Insérer une légende” dans Word Web

Ouvrez le document dans Word Bureau et utilisez Références → Insérer une légende.

Le complément ne se charge pas / l’URL ne correspond pas

  • Vérifiez que le manifest.xml de la branche main pointe bien vers la page GitHub Pages.
  • Après mise à jour, attendez quelques minutes que GitHub Pages déploie docs/.
